Every Claude Code session, in your menu bar

A compact macOS menu bar app that shows your Mac's CPU, memory and disk, and what each Claude Code session and subagent is doing right now.

Mac App Store: coming soonBuild from source

What it does

Sessions at a glance

Every live session with its project, title, busy or idle state, context size and time since last activity.

What each agent is doing

Busy sessions show the current step (tool call, thinking, writing), the last prompt and the latest reply.

Subagents too

Running subagents are listed under their session with their own current step.

System stats

CPU with a two-minute sparkline and load average, memory and swap, and free disk space.

Menu bar summary

C20% M71% ✳1/7: CPU, memory, and busy/total sessions, always visible.

Private by design

Reads local files only. No network requests, no analytics, no account.

Two editions

Built from source, the app also lists the top processes by CPU and memory and shows each session's CPU use.

The Mac App Store edition runs in Apple's App Sandbox, which does not let an app see other processes' CPU or memory, so those lists are left out. It asks once for read access to your .claude folder.
